# Create: Power up!

A Create addon for Minecraft **1.21.1** on **NeoForge**.

| | |
|---|---|
| Mod ID | `create_powerup` |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.235 (from the official 1.21.1 NeoGradle MDK) |
| Java | 21 |
| Build | Gradle 9.2.1 (wrapper) + NeoGradle `net.neoforged.gradle.userdev` 7.1.38 |
| Mappings | Mojang official + Parchment 1.21.1 / 2024.11.17 |

> Status: core device architecture only. No gameplay features (computers, robots, vehicles) are implemented yet.
> A full Gradle build against the real NeoForge dependencies has not been verified yet; run `./gradlew build` first.

## Requirements

* JDK 21 (the Gradle toolchain is set to 21 and can auto-download it via the foojay resolver)
* IntelliJ IDEA (Community or Ultimate)
* Internet access to `maven.neoforged.net`, `plugins.gradle.org` and `services.gradle.org` on first build

## Open in IntelliJ IDEA

1. **File > Open** and select the project folder (the one containing `build.gradle`). Choose *Open as Project*.
2. **Settings > Build, Execution, Deployment > Build Tools > Gradle**: set *Gradle JVM* to a JDK 21.
3. Wait for the Gradle sync to finish (the first sync downloads and decompiles Minecraft; this can take several minutes).
4. Run configurations are generated by NeoGradle during sync: pick **runClient** (or `runServer`, `runData`, `runGameTestServer`) in the run-configuration dropdown. If they do not appear, run the Gradle task `runClient` from the Gradle tool window (*Tasks > neogradle runs*) or via `./gradlew runClient`.

## Command line

```bash
./gradlew build        # compile, run unit tests, and produce build/libs/create_powerup-1.0.0.jar
./gradlew test         # unit tests only (pure Java components)
./gradlew runClient    # launch the Minecraft client
./gradlew runServer    # launch a dedicated server
./gradlew runData      # run data generators (output: src/generated/resources)
./gradlew --refresh-dependencies   # if libraries are missing in the IDE
```

Windows: use `gradlew.bat`.

## Architecture

* **Pure model** (`core`): `DeviceIdentity`, `DeviceType`, `DeviceState` and `PowerUpDevice` have no Minecraft dependency, so they are unit tested without the game. Persist an identity through its UUID and a state through `DeviceState.serializedName()`.
* **`PowerUpDevice`** is a small read-only interface (`identity()`, `deviceType()`, `state()`), designed to be implemented by a `BlockEntity` later. State is changed only on the logical server; clients display data received from it.
* **`DeviceRegistry`** is a NeoForge custom registry of `DeviceType`. Add a type during mod construction with `DeviceRegistry.registerType(name, factory)`; other mods can register into `DeviceRegistry.DEVICE_TYPE_KEY` with their own `DeferredRegister`. It is empty until features add types.
* **`PowerUpPermissions`** defines two boolean nodes (`create_powerup.device.access`, `create_powerup.device.configure`), default-allow, and checks them for a `ServerPlayer` through `PermissionAPI`. It is server-side only.
* **Client/server split:** common code lives in `PowerUp` and the packages above. Client-only code must go into a separate `@Mod(dist = Dist.CLIENT)` class.

### Extension points
* Implement `PowerUpDevice` on a `BlockEntity`, persist its identity and state, and register a `DeviceType` for it.
* Add permission nodes to `PowerUpPermissions`, or use dynamic context keys for per-device checks.
* Further subsystems (`computer`, `robotics`, ...) depend on `core`, never the other way round.

## Tests

`./gradlew test` runs the JUnit 5 tests (`junit_version` in `gradle.properties`). They cover only the pure components. `DeviceRegistry`, `PowerUpPermissions` and `PowerUp` need a running NeoForge environment and are not covered by unit tests.

## Enabling Create

Create is intentionally **not** an active dependency yet, because its exact Maven version string could not be verified when this scaffold was generated. What was verified from Create's official repository (tag `mc1.21.1-6.0.10`, the latest 1.21.1 release tag):

* Maven repository: `https://maven.createmod.net`, group `com.simibubi.create`, artifact `create-1.21.1`
* Create 6.0.10 builds against NeoForge 21.1.219, Flywheel 1.0.6, Ponder 1.0.82, Registrate `MC1.21-1.3.0+67`

To enable it:

1. Browse `https://maven.createmod.net/com/simibubi/create/create-1.21.1/` and pick the published version (set `create_version`, plus `flywheel_version`, `ponder_version`, `registrate_version` in `gradle.properties`).
2. Uncomment the repository and dependency blocks in `build.gradle`.
3. Uncomment the `create` dependency in `src/main/resources/META-INF/neoforge.mods.toml`.
4. Re-sync Gradle and run `./gradlew build`.
